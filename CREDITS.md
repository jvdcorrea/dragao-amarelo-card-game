# Créditos de assets

Preencha uma linha por arquivo ao trocar um placeholder. Ao trocar, ponha o `.ogg` com o mesmo nome base (o jogo prefere `.ogg` ao `.wav`) e apague a linha do placeholder.

Para sons do Kenney.nl: origem é o nome do pacote com o link (por exemplo, [Impact Sounds](https://kenney.nl/assets/impact-sounds)), autor Kenney (kenney.nl), licença CC0 1.0.
